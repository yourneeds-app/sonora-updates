# Sonora

**Your audiobooks. Your moment.** An Android app for your Audiobookshelf library, by [Your Needs](https://yourneeds.app).

[Download the latest version](https://github.com/yourneeds-app/sonora-updates/releases/latest) · [Discover Sonora](https://sonora.yourneeds.app)

You need an accessible Audiobookshelf server and access to your library. For most current Android phones and tablets, choose the **arm64-v8a APK** and install it over your existing Sonora installation. Updates are also available through the app.

Sonora is a fork of **Absorb**. The current release includes its corresponding source ZIP, licence notices and SHA-256 checksums.
